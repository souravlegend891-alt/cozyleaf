What Is a Kaomoji?

A kaomoji is a face built from text characters and read straight on, not sideways. A Western emoticon like :) needs a head-tilt to read as a smile, while a kaomoji such as (^_^) is drawn upright, with eyes, mouth and sometimes arms or ears arranged so it reads naturally. The word comes from the Japanese "kao" (face) and "moji" (character). The style started in Japan on early text-based forums, long before picture emoji existed, which is why these Japanese emoticons are still often called text faces. Kaomoji are sometimes grouped with ASCII emoticons, but they use far more Unicode symbols than basic keyboard characters.

Kaomoji vs. Emoji

Emoji are small pictures built into a device or app font, so the same 😀 can look different on iOS and Android. A kaomoji like (◕‿◕) is plain text and Unicode punctuation, so it can be typed, edited mid-face, or pasted where image emoji are stripped out, such as some usernames, old chat clients and plain-text fields.

Where Kaomoji Work Best

Because they are ordinary text, kaomoji paste cleanly into chat apps, captions, comments, forum posts, usernames and SMS. The shrug emoticon ¯\_(ツ)_/¯ and the table-flip emoticon (╯°□°）╯︵ ┻━┻ are so widely recognized because they render almost anywhere, from Discord to a basic text editor.

Common Mistakes to Avoid

  • Retyping a face by hand. One missing symbol breaks the face, so use the Copy button.
  • Long faces in short fields. Some platforms count every character, so an elaborate kaomoji can eat a short bio or username limit.
  • Systems that strip non-ASCII text. If a face disappears after pasting, try a simpler one built from common punctuation.

Most faces here use common Unicode characters and display well on major apps. A few use symbols from other scripts (for example Thai or Korean letters) that some older devices may show as boxes. If that happens, pick a simpler face from the same mood.
