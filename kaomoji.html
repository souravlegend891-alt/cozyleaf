What Is a Kaomoji?

A kaomoji is a face built entirely from text characters, made to be read straight on rather than sideways. Where a Western emoticon like :) needs a slight head-tilt to read as a smile, a kaomoji such as (^_^) is drawn upright — the eyes, mouth, and sometimes arms or ears are arranged so the face reads naturally without turning your head. The word itself comes from the Japanese "kao" (face) and "moji" (character), and the style originated in Japan in the early days of text-based online forums, long before picture-based emoji existed.

Kaomoji vs. Emoji — What's the Difference?

Emoji are small picture icons baked into a device or app's font — the same 😀 renders as an actual image, and its exact look varies slightly between iOS, Android, and different apps, sometimes changing meaning entirely between platforms. A kaomoji like (◕‿◕) is pure text and Unicode punctuation, not an image, so it looks identical everywhere it's supported. That also means a kaomoji can be typed character by character, edited mid-face, or dropped into places that strip out image-based emoji — old chat clients, some plain-text fields, and certain usernames that reject image characters but accept regular Unicode text.

Where Kaomoji Work Best

Because kaomoji are ordinary text, they paste cleanly into chat apps, social captions and comments, forum posts, usernames, and even plain SMS messages that don't support image-based emoji at all. The shrug ¯\\_(ツ)_/¯ and table-flip (╯°□°）╯︵ ┻━┻ have become widely recognized precisely because they're plain text — they render correctly almost anywhere, from Discord to a basic text editor, without depending on a particular emoji font being installed on the receiving end.

Common Mistakes to Avoid

  • Retyping a face by hand instead of copying it. It's easy to drop or mistype one of the small Unicode symbols and break the face entirely — copying the whole string with the Copy button avoids this.
  • Using a very symbol-heavy kaomoji in a field with a strict character limit. Some platforms count every character in a face separately, so an elaborate style can eat into a short bio or username limit faster than expected.
  • Pasting into a system that strips non-ASCII text. A few very old forms or legacy systems only accept basic keyboard characters — if a kaomoji disappears after pasting, try a simpler one built from more common punctuation.

Every kaomoji in this collection is curated to use widely-supported Unicode characters, so they're built to display consistently across major platforms like Discord, Instagram, WhatsApp, and X — rather than relying on rare symbol blocks that only render correctly on certain devices.
